# Buddy Bites 🤖
Your College Knowledge Companion

A college-specific chatbot that answers commonly asked student questions instantly, using a curated knowledge base of 100 Q&As.

🌐 Live Demo: https://buddy-bites-kit.netlify.app

## Problem
Students repeatedly ask the same basic college questions, and important information is hard to find quickly. New students often don't know where to look.

## Solution
Buddy Bites matches a student's question with a prepared knowledge base and displays the relevant answer instantly.

## How It Works
1. Student enters a question
2. Chatbot receives the question
3. Question is matched with the 100-question knowledge base
4. Relevant answer is selected
5. Answer is displayed

## Knowledge Base Categories
- College & Campus Information
- Departments & Courses
- Facilities
- Clubs & Student Activities
- Events
- Academic Information
- Student Services
- General College Queries

## Tech Stack
HTML, CSS, JavaScript, hosted on Netlify

## How to Run
Download `index.html` and open it in any browser. No installation needed.

## Future Scope
- Expand the question database
- Improve natural-language question matching
- Add event-related updates
- Integrate with student-accessible platforms
